# Select

A real `<select>` inside a `<label>`, restyled — not replaced.

```html
<syn-select [options]="effects" [(value)]="effect">Effect</syn-select>
```

## Why not a custom listbox

Replacing `<select>` means reimplementing, correctly, everything it already
does: the tab order, the arrow keys, Home/End, type-ahead, the ARIA combobox
pattern, and the native picker each platform draws — a full-screen wheel on
iOS, a system list on Android, the OS dropdown on desktop.

`appearance: none` leaves the closed state completely stylable, which is the
part that has to match the theme. Only the open list stays the browser's to
draw. That is the whole trade, and it is a good one.

## Options are an input, not projected content

```ts
export type SelectOption = {
  value: string;
  label: string;
  disabled?: boolean;
};
```

Two reasons. A component's encapsulated styles cannot reach projected
content — the same `_ngcontent` mismatch that stopped the card from styling a
projected `<img>` — and the shape of an option is worth having the compiler
check.

## The first-render trap

`[value]` on the `<select>` looks like the obvious binding and is wrong:

```html
<!-- does nothing on first paint -->
<select [value]="value()">
  @for (option of options(); track option.value) { … }
</select>
```

Angular applies the property binding on the `<select>` **before** `@for` has
rendered the options, so the value lands on an empty list and the browser
discards it. The control then shows the first option, whatever the model says.
The fix is to let each option decide:

```html
<option [value]="option.value" [selected]="option.value === value()"></option>
```

## States

<Canvas of={stories.Disabled} />

Both realistic. The whole control is disabled when the peripheral does not
support the capability at all — the Rust backend answers
`InterfaceUnsupported`. A single option is disabled when the effect exists in
OpenRazer but has no capability behind it yet, `reactive` being the current
example.

## Theming

The border is the primary colour, mixed down so it reads as a boundary rather
than a highlight:

```scss
border-color: color-mix(
  in srgb,
  var(--syn-primary) 45%,
  var(--syn-surface-container)
);
```

On focus it goes to full `--syn-primary`. The chevron is decorative and marked
`aria-hidden` — the native control still announces itself as a combobox.
